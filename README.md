# Gloomia

**Living wallpapers for your Windows desktop.**

[Website](https://gloomia.app) · [Download](https://github.com/nwalser/gloomia-releases/releases/latest) · [Changelog](https://gloomia.app/changelog) · [Report a bug](https://github.com/nwalser/gloomia-releases/issues)

---

## Wallpapers

- **Ambient**: Starfield · Aurora Flow · Hue Drift · Planet System
- **Reactive**: Neon Rain (CPU) · Aurora Flow (audio)
- **Live data**: Flight Radar · Critter Garden (weather) · Webcam
- **Aesthetic**: Matrix Rain · PCB Glow

## Why Gloomia

- **Lightweight**: native window, pauses when something is fullscreen so games and video keep all the GPU
- **Truly live**: smooth animation, not a looping video — many wallpapers react to your audio, CPU, weather, or the clock
- **Fully customizable**: speed, colors, density, palettes, and per-wallpaper toggles
- **Multi-monitor**: run a different wallpaper on each screen
- **Feels native**: lives behind your icons, no taskbar clutter, instant apply

## Download

Get the latest installer from the [**Releases**](https://github.com/nwalser/gloomia-releases/releases/latest) page. Windows 10 & 11.

- **Free**: most wallpapers are free, with full customization
- **Premium wallpapers**: a one-time purchase ($3.99–$4.99 each) — unlock with a license key, yours forever
